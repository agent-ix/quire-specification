# Mirrored implementation fixture rights

Files in this model directory are exact copies of newly authored model inputs
and generated producer outputs from quire-spec-language's implementation fixtures.
Those fixtures are AGPL-3.0-only. Their grant is preserved here; this does not
select a general license for the separate language standard or its prose.

The producer is the existing Filament TypeSpec frontend at 3b75e01. TypeSpec
1.15.0 is MIT; original producer/dependency grants are preserved. provenance.json
records generation inputs, exact bytes and qualification limits. These files are
mirrors for standalone review consumption; edits originate in the language
implementation fixture and are recompiled, then mirrored by exact byte digest.
No compiled output is hand-patched to match an expectation.
