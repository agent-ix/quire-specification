# Native state core: proposed interface packet

Status: **proposed, private review, not an accepted standard or implementation**.
Standard-wide prose/reusable-artifact terms remain unsettled. Mirrored native
implementation fixtures retain the grants in their rights records. All examples
are newly authored synthetic data; no application specification or third-party
grammar is copied.

Read [the profile](profile.md), [the shared boundary](boundary.md), and the
[fixture expectations](fixtures/README.md) together. These files are intended
to become a self-contained publication candidate after semantic, rights and
independent-consumer qualification. Their presence is not that qualification.

The language defines meaning independently from any one executable IR. This
proposal admits a finite state profile with identity-preserving object
references. It proposes no temporal, protocol, relational or method/result AST.
Recognized unsupported obligations remain source-addressable.

The implementation milestone is an aggregate/parent-graph workflow with healthy,
violating, invalid, unsupported and incomplete inputs. The full assignment also
requires parsing/formatting, model linking, independent reference evaluation,
qualified generated execution and an opaque-clause extraction adapter. A fixture
packet, parser-only milestone or sampled parity run does not complete that work.

Separate review records track owner decisions and inspected implementation
facts. Those records are outside the candidate publication file set. The
candidate remains a draft until semantic and artifact reviews are complete.

The [FS02 shared model/reference amendment](model-contract.md) defines the proposed
byte/semantic reference split, exact native import digest meaning, and existing
model adapter responsibilities for B/C review. It does not freeze interchange.
