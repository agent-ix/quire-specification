### Round 1 evidence for FND-001

This same presence/value rule applies to each `QueueGrowthJob` template and `QueueGrowthTransition` in a `queue_growth` witness: all carry the checked value if declared and omit it otherwise. A supplied priority must equal the checked task declaration, and a missing or extra priority is a replay refusal for either carrier.
