## Description

Exercise original-byte source authority and the carried-forward anchor table.
Planned; alias/composite pre-expression correspondence requires FS03 completion.

## Test Procedure

Run valid named invariant/current, precondition/pre and postcondition/post
bindings, with postcondition pre-state access to the same operation. Mutate
source bytes/revision/span, duplicate inline/file authority, clause identity,
model declaration identity and operation anchor separately. Offer a bare context,
result in invariant/precondition, pre in invariant/precondition, pre(parameter),
and a pre guard used for a post optional value. Preserve original and extracted
source spans in the actual Markdown/native consumer path.

## Expected Results

Valid cases bind exactly one source and the intended immutable observation.
Each mutation refuses before lowering with a typed cause and original locus.
The historical pre(parameter) success is a composed-profile refusal; it does not
prove correspondence for aliases or composite pre expressions.
