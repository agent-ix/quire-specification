# TC-275: One-arm counterexample entry

## Description

Show that an FR-331 `counterexamples` entry names exactly one of the
transcript's `artifacts` entry or the canonical assignments of a
counterexample with no transcript, never both, and that a transcript-backed
entry's assignments are its decode rather than a separately stored duplicate.

## Preconditions

- FR-197's `ReplaySource` structural separation (`Witness`/`Input`) exists.
- The FR-331 `artifacts` property carries immutable generated bytes with
  kind, identity and source map.

## Test Procedure

Build FR-331 `counterexamples` entries for a `Witness`-arm counterexample and
an `Input`-arm counterexample, and construct the malformed cases that name
both or neither. Execute each vector through the real local Rust boundary and
read back the admitted entry or refusal.

## Vectors

| Vector | Mutation | Expected result | Criteria |
| --- | --- | --- | --- |
| OA-01 | A `Witness`-arm counterexample's entry | Names the transcript's `artifacts` entry only; its assignments are that entry's decode | FR-331-AC-9 |
| OA-02 | An `Input`-arm counterexample's entry | Names its canonical assignments only, with no `artifacts` entry | FR-331-AC-9 |
| OA-03 | An entry naming both the `artifacts` entry and stored canonical assignments | Refused with a typed cause before admission | FR-331-AC-9 |
| OA-04 | An entry naming neither the `artifacts` entry nor canonical assignments | Refused with a typed cause before admission | FR-331-AC-9 |
| OA-05 | A `Witness`-arm entry's assignments read back twice | Both reads equal the transcript's decode; no second stored copy exists | FR-331-AC-9 |

## Expected Results

OA-01 and OA-02 find each arm's entry naming exactly its own source. OA-03
and OA-04 find the mutually-exclusive rule enforced by refusal. OA-05 finds
the `Witness`-arm entry storing no assignments beside the transcript decode.
