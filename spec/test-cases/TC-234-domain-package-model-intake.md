# TC-234: Domain package model intake

## Description

Admit a domain package lifted from an artifact bundle, and mutate its identity, nodes and references.

## Test Procedure

Use the subject and inputs named by FR-154. Execute its positive case, each declared boundary, and each explicit refusal mutation through the real local Rust boundary; compare the complete typed result and artifact accounting with the criterion.

Select `quire.model.complete/v1` through
[`model-complete.md`](../../proposals/quire-v1/definitions/model-complete.md).
Node names and declaration keys follow TC-195.

Fixtures:

- **B1** (artifact bundle): the `entity` artifact with id `A` and title
  `Alpha`, with a Properties row for field `x` typed `A`, presence `optional`,
  multiplicity `0..1`; and the `entity` artifact with id `B` and title `Beta`,
  with `specializes: A`.
- **K1**: the domain package that quire-rs extraction and the FCD
  extraction-frontend lift produce from B1, with identity `test/orders` and
  version `1`: TC-195 F1's three IR nodes, each with its FCD `origin`.
  Its `constructs` table has one entry, for kind
  `{module: test/objects, name: entity}`, whose `meaning` is
  `quire.meaning.model.object-type/v1`; types `A` and `B` name that kind and
  carry `displayName` `Alpha` and `Beta`.
- **S1**: `model M = "test/orders";`. It carries no digest and no version.
